Role Players — Standalone

Self-contained copies of the Timer, Ah-Counter, and Grammarian tools. No server, no install, no internet connection required — open any of these files directly in a browser. Each one saves its sessions to this browser's local storage only.

⏱ Timer
Live speech timing with green/yellow/red thresholds.
👂 Ah-Counter
Tally filler words, crutch words, and pauses.
🔤 Grammarian
Track word/idiom usage and grammar corrections.

These pages are independent of the main Toastmasters Dashboard app — data saved here does not sync with it, and data saved in the app doesn't show up here. Each tool keeps its own local storage.
